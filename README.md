# Unity_ShaderShowCase
今までやってきたシェーダーのまとめ

■ 開発環境・使用技術
----------------------------------------------------------------------
・Engine          : Unity 6 (0.58f1)

・Render Pipeline : Universal Render Pipeline (URP)

・Shading Language: HLSL

・Input           : Unity Input System



■ 収録シェーダー・機能一覧 
----------------------------------------------------------------------

● 01. ろうそくの炎 (Candle Flame) [開発期間: 7日]
頂点ビルボードとFBMによる炎の揺らぎを実装し、ComputeShaderの距離判定で1万個の並列制御を実現。

■ デモシーンの操作方法
・視点移動              : マウス右クリックホールド ＋ マウス移動
・カメラ移動 (前後左右) : W / A / S / D キー
・カメラ移動 (上下)     : Q / E キー

● 02. シルエット透過 (Silhouette Occlusion) [開発期間: 4日]
2パス目のZTest Greaterと深度オフセット制御により、障害物の裏に隠れた際のシルエットをちらつきなく描画。

● 03. ディゾルブ (Dissolve) [開発期間: 2日]
ノイズテクスチャと進行度のstep比較で透過を制御し、閾値の差分マスクによって消滅境界のエッジを動的に描画。

● 04. ホログラム (Hologram) [開発期間: 3日]
四則演算の軽量な擬似乱数でノイズの規則性を排し、カメラ右方向への頂点変位でどの角度でも破綻しないグリッチを実現。

● 05. 海 (Ocean) [開発期間: 3日]
波の数式の偏微分から接空間基底と解析的法線を直接導出して計算負荷を削減し、ヤコビアン行列の活用で海面を表現。

● 06. 波紋 (Ripple) [開発期間: 10日]
正弦波の偏微分による解析的法線と角周波数制御に加え、smoothstepと寿命判定でアーティファクトと負荷を軽減。

■ デモシーンの操作方法
・波紋の生成            : 画面上の水面オブジェクトをマウス左クリック

● 07. トゥーン (Toon) [開発期間: 10日]
頂点カラーの平滑化法線展開でハードエッジのアウトライン割れを防ぎ、指向性リムライトや環境光統合で陰影を構築。

● 08. ブルーム・描画パス制御 (Selective Bloom) [開発期間: 3日]
9タップ畳み込みと特定パスの選択的抽出を実装し、LoadAction制御とPassData分離で帯域負荷とGCを削減。

● 09. 虹色表現 (Rainbow) [開発期間: 3日]
色相変化に対するRGB各要素の位相の動きを数式化してHSVからRGBへ変換し、滑らかな虹色グラデーションを表現。
